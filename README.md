# Iris Data Analysis and PCA

## Project Description

This project performs an exploratory data analysis (EDA) and Principal Component Analysis (PCA) on the Iris dataset.

It includes statistical analysis, data visualization, correlation study, and dimensionality reduction using PCA.

## Technologies Used

* Python
* pandas
* numpy
* matplotlib
* seaborn
* scikit-learn

## Dataset

The dataset is stored in an Excel file named `IRIS.xlsx`.

## Features

* Descriptive statistics (mean, standard deviation, grouped statistics)
* Data visualization (histograms, boxplots, scatterplots, pairplots)
* Correlation matrix and heatmap
* Eigenvalues and eigenvectors computation
* PCA using:

  * Manual computation
  * scikit-learn
* Projection of individuals on principal components
* Correlation circle visualization

## How to Run

Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn openpyxl
```

Run the script:

```bash
python datasetiris.py
```

## Results

The project highlights:

* The most significant variables contributing to PCA
* The variance explained by each principal component
* Relationships between features through visualization
